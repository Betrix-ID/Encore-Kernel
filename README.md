# Encore Setup 🍃
Adalah shell script C yang saya buat untuk 
Mengontrol bagaimana Profile Kernel Memantau 
perfromnace untuk meningkatkan resfonsivitas 
sistem secara keseluruhan

## Metode Optimasi❓️
- mengoptimalkan kinerja sistem Android. Dengan menyesuaikan pengaturan kernel dan membersihkan cache aplikasi, utilitas ini bertujuan untuk meningkatkan respons sistem, mengurangi beban latar belakang, dan memberikan pengalaman penggunaan yang lebih lancar.

## Efek yang Diperoleh ❓️
- Faster performance: Mengurangi beban kerja yang tidak perlu.
- Stabilitas lebih baik: Membatasi aplikasi yang terlalu banyak berjalan di latar belakang.
- Efisiensi sumber daya meningkat: Memaksimalkan penggunaan RAM dan CPU.
- Smooth experience: Transisi aplikasi lebih halus setelah cache dibersihkan.
- Longer battery life: Mengurangi aktivitas latar belakang yang tidak diperlukan.
> Effect may vary depending on the device and system version.
